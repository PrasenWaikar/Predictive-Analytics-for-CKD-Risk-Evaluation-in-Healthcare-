# Predictive-Analytics-for-CKD-Risk-Evaluation-in-Healthcare-

📌 𝑷𝒓𝒐𝒋𝒆𝒄𝒕 𝑶𝒗𝒆𝒓𝒗𝒊𝒆𝒘

This project focuses on developing a machine learning model to predict the risk of Chronic Kidney Disease (CKD) in patients. By analyzing medical records and patient health indicators, the model aids healthcare professionals in early detection, allowing for timely intervention and better patient outcomes.


❓ 𝑷𝒓𝒐𝒃𝒍𝒆𝒎 𝑺𝒕𝒂𝒕𝒆𝒎𝒆𝒏𝒕:

Chronic Kidney Disease often progresses silently until it reaches advanced stages. Early diagnosis is crucial to manage the condition effectively. However, manual diagnosis based on numerous clinical parameters is time-consuming and prone to error. The goal of this project is to build a predictive model that can automatically evaluate the risk of CKD based on patient data, thereby assisting doctors in clinical decision-making.

✨ 𝑲𝒆𝒚 𝑯𝒊𝒈𝒉𝒍𝒊𝒈𝒉𝒕𝒔:

▪️Performed thorough exploratory data analysis (EDA) to identify key risk factors and understand distributions and relationships between variables.
▪️Handled missing values, imbalanced data, and categorical variables through appropriate preprocessing techniques.
▪️Implemented classification models including Logistic Regression, Random Forest, K-Nearest Neighbors (KNN), and Support Vector Machines (SVM).
▪️Evaluated model performance using metrics such as confusion matrix, accuracy, precision, recall, F1-score.
▪️Applied hyperparameter tuning and cross-validation to optimize model performance.
▪️Visualized results and health patterns using Matplotlib and Seaborn for effective communication with stakeholders.
 Deployed the model using Streamlit
